# 🚢 Titanic Dataset - Exploratory Data Analysis (EDA)

This project focuses on performing Exploratory Data Analysis (EDA) on the Titanic dataset using Python. The goal is to clean the data, analyze survival patterns, and visualize insights.

---

## 📊 Project Overview
The Titanic dataset was analyzed to understand how different factors affected passenger survival.

---

## 🛠️ Steps Performed

### 1. Data Cleaning
- Filled missing values in the Age column using mean
- Dropped the Cabin column due to excessive missing values

### 2. Data Analysis
- Survival Rate by Age Group
- Survival Rate by Embarked Port
- Survival Rate by Family Size

### 3. Data Visualization
- Histogram (Age Distribution)
- Heatmap (Correlation Matrix)
- Bar Plot (Survival vs Family Size)

---

## 📈 Key Insights
- Children had higher survival rates compared to adults and seniors
- Passengers from certain embarkation ports had better survival chances
- Smaller families had higher survival rates
- Passenger class and fare influenced survival
